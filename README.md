# Rimhammer-map-from-TWW-3
A test version of a map based on the Total War: Warhammer III "Immortal Empires" campaign map. It replaces RimWorld’s standard map generator with a fixed, pre-defined geography. Rivers, lakes, some mountain ranges, and biomes that do not align with standard climatic zones are generated procedurally. The "Harmony" mod is required for installation.
